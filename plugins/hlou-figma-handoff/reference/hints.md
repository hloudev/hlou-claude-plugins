# Section hints

Written into `pages[].sections[].hints`. Documented, not enforced: an unknown hint is
read as plain text. `<key>` is a collection key, `<n>` a count. Generated by
`scripts/refresh-references.mjs`; do not edit by hand.

| Hint                  | Means                                                            |
| --------------------- | ---------------------------------------------------------------- |
| `slider`              | Slides that replace one another in place (hidden ones included). |
| `carousel`            | A horizontally scrolling row of cards, several visible at once.  |
| `gallery`             | A grid of images.                                                |
| `lightbox`            | Images that open full-screen on click.                           |
| `tabs`                | Panels switched by a row of tabs; one visible at a time.         |
| `accordion`           | Questions or rows that expand in place.                          |
| `form`                | Fields and a submit button.                                      |
| `booking-bar`         | A compact date / guests / search bar.                            |
| `steps`               | A step indicator (« STEP 2 OF 4 ») of a multi-step flow.         |
| `summary`             | The recap panel of a flow (selection, totals).                   |
| `menu-trigger`        | The control that opens the menu overlay.                         |
| `collection:<key>`    | Repeated cards that are records of collection <key>.             |
| `hidden-siblings:<n>` | Has <n> hidden siblings of the same size (states or slides).     |
